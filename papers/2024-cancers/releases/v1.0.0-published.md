## HCC Surveillance Markov Model: code as published (Cumming et al. 2024)

The R scripts and data exactly as used for

> Cumming J, Scott N, Howell J, et al. **Improving Hepatocellular Carcinoma Surveillance Outcomes in Patients with Cirrhosis after Hepatitis C Cure: A Modelling Study.** *Cancers* 2024, 16(15), 2745. https://doi.org/10.3390/cancers16152745

**Results match the publication: yes.** This is the original code, kept unchanged.

### Contents

This archive is complete: all data files are included (at this commit they
were plain git files, not Git LFS).

| File | Role |
|------|------|
| `Sensitivity_analyses.R`, `bootstrapped_param_calcs.R`, `Progression Model HCC.R`, `Clinical Scenarios.R` | Original analysis scripts |
| `Parameters.csv`, `Parameters_25.csv` | Parameter inputs |
| `list_of_resampled_milton_output.rds` | Bootstrap resamples of the calibration data (HPC, 2024). **Cannot be regenerated** (see below) |
| `miltonoutput.rds` | Bootstrap MLEs (HPC, 2024). **Cannot be regenerated** |
| `resampled_pars.rds`, `resampled_pars_fin.rds`, `param_names.rds` | Derived results and the values quoted in the paper |

SHA-256 of the two files that cannot be regenerated. Later releases use exactly
these bytes:

```
d04ea6ad05824b90c7c538be71503d6cd265456277d1650f2e20fb69ffa42a8c  list_of_resampled_milton_output.rds
005441daa3b6dd09cacc0081650070b91a89938b4ea5817b95fce8e13cdd34a1  miltonoutput.rds
```

Why they cannot be regenerated: the resampling code is in
`bootstrapped_param_calcs.R` (commented out, `set.seed(314)`). Rerunning it
reproduces the first five of the 10,000 resamples exactly, then diverges,
because the exact probability vector used for the HPC run was not recorded.

### Running it

The scripts predate the refactor: they use flat paths, have no lockfile and no
tests, and `Sensitivity_analyses.R` must be run first. **For a pinned
environment that gives the same numbers, use `v1.1.0` instead.**
`hypogeom` is installed with `remotes::install_github("damian-t-p/hypogeom")`.

### Later versions

- `v1.1.0`: refactored, tested and pinned with renv; reproduces these results.
- `v1.2.0`: corrected calibration (exact likelihood, refitted bootstrap); some
  intervals differ from the publication.
